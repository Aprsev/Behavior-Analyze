# OpenCV super-resolution model weights

Place downloaded OpenCV `dnn_superres` TensorFlow weights here. They are runtime
assets and are ignored by Git.

The filename must match the GUI method and scale, for example:

- `EDSR_x4.pb` for Method `edsr`, Native SR scale `4`
- `FSRCNN_x4.pb` for Method `fsrcnn`, Native SR scale `4`
- `ESPCN_x4.pb` for Method `espcn`, Native SR scale `4`
- `LapSRN_x4.pb` for Method `lapsrn`, Native SR scale `4`
